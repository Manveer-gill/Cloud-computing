1. Introduction to Subnetting

Subnetting is the process of dividing a large IP network into smaller networks called subnets. It helps network administrators manage IP addresses and organise devices more efficiently.

What is an IP Address?

An IP address is a logical address used to identify a device on a network. An IPv4 address contains 32 bits and is normally written as four decimal numbers separated by dots.

Example: 192.168.1.10

Why is Subnetting Used?

  • To divide a large network into smaller networks.
  • To use IP addresses more efficiently.
  • To organise devices into separate network segments.
  • To make network management easier.
  • To help control broadcast traffic within a network.

What is a Subnet Mask?

A subnet mask identifies the network portion and host portion of an IPv4 address. For example, the subnet mask 255.255.255.0 is equivalent to the CIDR prefix /24.

2. Common IPv4 Subnet Masks

The following table shows some commonly used IPv4 subnet masks and their address capacities.

CIDR Prefix Subnet Mask Total Addresses Usable Hosts*
/24 255.255.255.0 256 254
/25 255.255.255.128 128 126
/26 255.255.255.192 64 62
/27 255.255.255.224 32 30
/28 255.255.255.240 16 14
/29 255.255.255.248 8 6
/30 255.255.255.252 4 2

*Usable host counts assume conventional IPv4 subnets, excluding the network and broadcast addresses. Special cases such as /31 and /32 are not shown.

3. Solved Subnetting Examples

Example 1: Find the usable hosts in /26

Step 1: Find the host bits.

Host bits = 32 - 26 = 6

Step 2: Calculate total addresses.

26 = 64 addresses

Step 3: Calculate usable hosts.

64 - 2 = 62 usable host addresses

Answer: 62 usable hosts.

Example 2: Find the subnet mask for /27

The CIDR prefix /27 means that 27 bits are used for the network portion of the address.

Subnet Mask: 255.255.255.224

Host bits = 32 - 27 = 5

Total addresses = 25 = 32

Usable host addresses = 32 - 2 = 30

Example 3: Find the network address

IP Address: 192.168.1.70

Subnet Mask: 255.255.255.192 (/26)

Block Size: 256 - 192 = 64

The subnet ranges in the last octet are 0-63, 64-127, 128-191 and 192-255.

Since 70 lies between 64 and 127, the network address is 192.168.1.64.

Answer: 192.168.1.64
